# Lagou (拉勾招聘)

> Lagou is a Chinese online recruitment platform operated by Beijing Lagou Network
> Technology Co., Ltd., specializing in hiring for the internet and technology
> sector. It connects software engineers, product managers, designers and other
> digital-economy professionals with employers across major Chinese cities, and
> runs companion products for enterprise recruiting, campus recruiting and
> professional education. Lagou publishes NO public API and no developer portal;
> this file is generated by API Evangelist from the catalog profile, not fetched
> from the provider.

## About

- [Lagou](https://www.lagou.com/): Main job-seeker recruitment site.
- [About Lagou (关于我们)](https://www.lagou.com/about.html): Company overview and legal entity.
- [Company directory (企业招聘信息)](https://www.lagou.com/gongsi/): Browseable directory of hiring companies.
- [Job search (招聘)](https://www.lagou.com/wn/zhaopin): Job listing search across cities.

## Products

- [Lagou Enterprise (拉勾企业版)](https://easy.lagou.com/): Employer-side recruiting product.
- [Lagou Campus (拉勾校园)](https://xiaoyuan.lagou.com/): Campus / graduate recruiting.
- [Lagou Education (拉勾教育)](https://kaiwu.lagou.com/): Professional-skills course platform.

## Developer

- No public API, developer portal, API reference, OpenAPI description, SDK, CLI or MCP server was found.
- `open.lagou.com` resolves and is titled "拉勾开放平台" (Lagou Open Platform) but serves only a truncated stub page with no documentation, no endpoint reference and no registration flow.
- `api.lagou.com` responds to a root request with a bare `SUCCESS` body and exposes no documented, publicly consumable endpoints.
- No `/.well-known/` discovery documents are published. Lagou returns a styled HTML error page with HTTP 200 for unknown paths, so status codes alone are misleading on this domain.
